# kavkaz_fines — штрафы

- **`/fine [ID]`** — полиция и ДПС на смене (`Config.Jobs`), нарушитель в 6 м. выбор статьи, сумма (не выше потолка статьи), описание;
- **`/fines`** — игрок видит свои неоплаченные штрафы и оплачивает с карты;
- через **3 дня** неоплаченный штраф **удваивается** (один раз);
- после оплаты **10%** уходит инспектору на карту (даже если он не в сети);
- статьи и суммы — `config.lua` (превышение, красный, тонировка, грязный/подложный номер, без номера, СГУ, без прав, парковка, кортеж);
- пробивка номера ДПС (`kavkaz_plates`) показывает, сколько неоплаченных штрафов у владельца.

таблица `kavkaz_fines` создаётся сама (схема — `sql/2026-11-10_kavkaz_fines.sql`).
