# kavkaz_help — все команды в одном месте

Один список команд — [`config.lua`](config.lua). Из него берутся:

- **подсказки в чате** при вводе «/» — русский текст и параметры. Админ-команды видны только на смене и с нужным уровнем; `/alogin` и `/apin` — любому админу;
- **окно `/help`** (или `/команды`) — вкладки «Общие», «Чаты», «Работа и штрафы», «Номера», «Админ» (вкладка «Админ» только на смене);
- **вкладка «Команды» в админ-панели F10** — по уровням, клик копирует пример (export `GetAdminCommands`).

## новая команда

Одна строка в `config.lua`:

```lua
C{ tab = 'chats', cmd = 's', p = { { 'текст', 'что кричишь' } }, ex = '/s Стой!', desc = 'крик, слышно на 40 м' }
```

Для админ-команды добавь `perm = 'ключ из kavkaz_admin Config.Perms'` — уровень возьмётся оттуда.

## почему подсказки накладываются заново

Встроенный чат при старте любого ресурса рассылает имена всех разрешённых команд (и этим возвращает скрытые),
а ox_lib — английские подсказки `(type: …)` всем игрокам. Поэтому клиент после каждой такой рассылки
(через 1 с тишины) заново накладывает наш список.

## проверка

Через 10 с после старта сервер пишет в консоль:

- `в списке есть, на сервере нет команды` — опечатка в `config.lua` или ресурс не запущен;
- `команда есть, а в списке kavkaz_help её нет` — добавь строку.

Дубли имён с Qbox (`/report` в qbx_adminmenu) эта проверка не видит: сервер отдаёт одну запись на имя. Они перечислены в `docs/commands.md`.

Клиентские команды проверяет первый вошедший игрок, отчёт тоже в консоли сервера.
