# kavkaz_sgu — СГУ «Хазард 7007»

по docs/vision/04-cars.md. звук синтезируется в игре (`html/index.html`, WebAudio) — без звуковых файлов и чужих записей.
предпросмотр звука: открыть `html/index.html?preview` в браузере.

| клавиша | что |
|---|---|
| G | кряк (у всех моделей) |
| J | мелодия вкл/выкл |
| U | следующая мелодия |
| O | стробоскоп фарами (только «Про») |

H не берём: на ней фары GTA и поиск ключей qbx_vehiclekeys. игрок может переназначить в настройках FiveM.

- **модели:** Мини 30 000 ₽ (кря-кря), обычная 120 000 ₽ (4 мелодии, в т.ч. фирменная «Хазард»), Про 250 000 ₽ (8 мелодий + стробоскоп);
- **установка:** гараж Бислана (731, −1088): подъехать за рулём своей машины из гаража → `[E]`. деньги — наличные, потом карта; снять — бесплатно;
- **служебное СГУ:** на смене (`leo`/`ems`) в машине экстренных служб или служебной из `kavkaz_cars` (`sale = 'org'`). штатные американские сирены заглушены;
- **ДПС/ФСБ:** Alt на машине → «Проверить СГУ» → «Изъять»; штраф `/fine ID sgu` (kavkaz_fines);
- **админ:** `/asgu mini|std|pro|off` — на свою машину из гаража, в которой сидишь;
- хранится в таблице `kavkaz_sgu` (`sql/2026-11-10_kavkaz_sgu.sql`) по `player_vehicles.id`.

кряк рассылается игрокам в радиусе 140 м, мелодия и стробоскоп — state bag машины (`sgu_tone`, `sgu_strobe`).
