# kavkaz_traffic — русский поток машин

- машины NPC (классы: седаны, компакты, внедорожники, купе, фургоны и т. п.) заменяются нашими моделями из `kavkaz_cars`:
  Приора, 2114, 2110, 2109, Веста, Логан, Ларгус, Фокус, Октавия, Мондео, изредка M5. доли — `Config.Models`;
- подмена только **вдали (110 м+) или вне экрана**, не ближе 45 м — игрок не видит, как машина «превращается»;
- водитель остаётся того же вида, машина едет дальше по правилам; цвет и грязь случайные;
- у всех машин NPC **русские номера** (`А 123 ВС 95`, регионы по весам `Config.Regions`), «красивые» номера NPC не выпадают;
- в потоке нет американской полиции, шерифов, такси, школьных автобусов; среди прохожих нет LSPD, шерифов, банд ЛС и реднеков;
- машины игроков, скриптовые, служебные и машины с игроком внутри не трогаются.

тяжёлые модели (2107, Гранта, Камри, Крузак, Гелик, Zeekr, Газель) выключены до перепаковки текстур — в `config.lua` есть пометка.

## что проверить в игре
проехать по городу 5 минут: в потоке должны быть наши машины, номера русские, без подтормаживаний. если тормозит — уменьшить
`Config.PerTick` до 1 или увеличить `Config.Interval`.
