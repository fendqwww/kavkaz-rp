# kavkaz_rp — RP-чаты и /pay

команды из `docs/vision/07-mechanics.md` («Чаты и команды»). дальности и цвета — в `config.lua`. мут из `kavkaz_admin` блокирует все чаты.

| команда | что | кто видит |
|---|---|---|
| обычный чат | речь персонажа «Имя Фамилия говорит» | рядом, 15 м (`Config.LocalChat`) |
| `/s текст` | крик | 40 м |
| `/w ID текст` | шёпот (вплотную) | один игрок |
| `/me` | действие — **из qbx_core** | рядом |
| `/do текст` | описание окружения | рядом |
| `/try текст` | попытка: «удачно» / «неудачно» (50/50) | рядом |
| `/todo фраза*действие` | «Привет», — сказал Ахмед, пожимая руку | рядом |
| `/b текст` | локальный NonRP | рядом |
| `/pm ID текст` | личное OOC | один игрок |
| `/r`, `/rn` | рация организации IC / NonRP (госструктуры — только на смене) | своя работа |
| `/d` | департамент: МВД, ФСБ, больница, МЧС на смене | госструктуры |
| `/f`, `/fn` | семья / банда IC / NonRP | своя банда |
| `/gov` | госновости (ранг isboss госструктуры) | весь сервер |
| `/pay ID сумма` | передать наличные (до 3 м, с анимацией) | — |

`/ooc` (глобальный OOC) остаётся из qbx_core.
