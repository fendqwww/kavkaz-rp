# kavkaz_interact — меню действий на G

- **держать G** — вокруг крестика появляются «таблетки»; навёл мышь, отпустил G — действие выполнено. в центре — отмена, Esc / ПКМ — закрыть;
- **коротко G** за рулём машины с СГУ — кряк (как раньше; кряком теперь управляет это меню через `exports.kavkaz_sgu:Quack()`);
- за рулём: капот, багажник (крышка), двери (подменю), ремень, замок, зажигание, фары, выйти. точка у пункта — «включено/открыто»;
- пассажиром: ремень, выйти. рядом с машиной пешком: капот, багажник, замок (закрытую на ключ не открыть);
- пешком: руки вверх, паспорт (меню F4), навигатор, команды;
- ремень, замок и зажигание — штатные действия Qbox (те же проверки ключей и анимации, что у клавиш B и L);
- вещи в багажнике и бардачке — по-прежнему через ALT (ox_inventory); пункты и клавиша — `config.lua`.
