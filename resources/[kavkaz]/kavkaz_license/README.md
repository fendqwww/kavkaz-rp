# kavkaz_license — водительские права

Получают права в автошколе (kavkaz_quests, Зарема Поворотовна): теория + вождение → предмет `driver_license`
и `metadata.licences.driver = true`. Этот ресурс — всё, что после:

| команда | кто | что |
|---|---|---|
| `/prava` | любой | свои права: есть, нет, лишён до какого числа |
| `/prava ID` | ДПС на смене, рядом | проверить водителя по базе |
| `/lishit ID дни причина` | ДПС на смене, рядом | лишить прав на 1–30 дней; карточка изымается |
| `/agivelicense ID`, `/atakelicense ID` | админ 4+ | выдать (снимает лишение) / забрать |

- срок вышел — права возвращаются сами (при входе и раз в минуту), карточка снова в инвентаре;
- пока лишён — автошкола не принимает пересдачу;
- сел за руль без прав — одно предупреждение; ездить можно (это RP: ДПС штрафует через `/fine`);
- лишение хранится в `metadata.driver_ban = { untilTs, reason, by }`; для других ресурсов есть export `HasLicense(src)`.
