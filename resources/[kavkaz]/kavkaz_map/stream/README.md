# stream — свои файлы карты

сюда кладутся файлы из CodeWalker: `.ymap` (расстановка), `.ytyp` (описания моделей), `.ydr` / `.ytd` / `.ybn` (модели, текстуры, коллизии).
FiveM грузит всё из этой папки сам, после `ensure kavkaz_map` или перезапуска сервера.

если в папке есть `.ytyp` — допиши его в `fxmanifest.lua` строкой `data_file 'DLC_ITYP_REQUEST' 'stream/имя.ytyp'`
(или попроси Claude).

чужие моды сюда не кладём: для них есть `setup/import-mods.ps1`, он сделает каждому моду отдельный ресурс.
