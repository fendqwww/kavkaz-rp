# kavkaz_admin — админка KAVKAZ RP

реализация плана `docs/vision/01-admin.md`: уровни 1–6, вход на смену по PIN, команды, панель F10, репорты,
наказания (переживают перезаход), логи в базу и в Discord.

## как стать админом
1. **основатели (уровень 6)** — все, у кого ACE `kavkaz.founder`. в `overrides/kavkaz.cfg` оно выдано `group.admin`,
   а в `group.admin` по рецепту Qbox уже стоит владелец сервера. второго основателя добавить в `permissions.cfg`
   (или в `server.cfg`): `add_principal identifier.fivem:12345678 group.admin`.
2. **остальные** — основатель или главный админ на смене пишет `/setadmin ID уровень` (0 — снять).
   главный админ (5) назначает только 1–4; основатель — любой.
3. админ заходит как обычный игрок → `/alogin` → при первом входе придумывает PIN из 6 цифр (в базе только bcrypt-хэш).
   3 неверных PIN — блок на 15 минут и сообщение в Discord. `/apin` — сменить PIN, `/aresetpin ID` — сброс (ур. 6).
4. `/alogout` — сдать смену. часы смен и закрытые репорты копятся в `kavkaz_admins` (панель → «Состав и часы смен»).

без смены ни одна админ-команда не работает, даже у основателя.

## клавиши
| клавиша | что |
|---|---|
| **F10** | панель (или `/apanel`) |
| **F2** | noclip: WASD, Q/E вверх-вниз, SHIFT быстрее, CTRL медленнее |
| **F3** | телепорт мышкой: появляется курсор, ЛКМ — перенестись в точку (земля, крыша, дорога), ПКМ — выйти |

ALT, как в плане, занят ox_target (глазок), поэтому клик-ТП на F3. клавиши меняются в GTA → Настройки → Привязка клавиш → FiveM.

## команды
названия с `a` в начале — там, где Qbox уже занял имя (`/tp`, `/tpm`, `/car`, `/dv`, `/givemoney`, `/setjob`, `/revive`, `/aheal`).
команды Qbox остались, но работают только у `group.admin` после `/optin` и **не пишут лог** — пользуемся нашими.

| команда | что | ур. |
|---|---|---|
| `/report текст` | написать администрации (любой игрок, раз в минуту) | — |
| `/goto ID`, `/bring ID` | ТП к игроку / к себе | 1 |
| `/spec ID` | наблюдать (BACKSPACE или `/spec` — выйти) | 1 |
| `/a текст` | админ-чат | 1 |
| `/admins` | кто на смене | 1 |
| `/kick ID причина` | кик | 2 |
| `/mute ID мин причина`, `/unmute ID` | мут чата и голоса | 2 |
| `/ajail ID мин причина`, `/unjail ID` | админ-тюрьма (до 60 мин у ур. 2) | 2 |
| `/warn ID причина` | предупреждение, 3 = бан на 3 дня | 2 |
| `/arevive [ID]` | поднять и вылечить | 2 |
| `/freeze ID` | заморозить / разморозить | 2 |
| `/check ID` | карточка: деньги, работа, машины, варны, баны, совпадение IP | 2 |
| `/afix`, `/aflip` | починить и заправить / перевернуть машину | 2 |
| `/adv [радиус]` | удалить свою машину или пустые в радиусе | 2 |
| `/ban ID дни причина` | бан (ур. 3 — до 7 дн., 4 — до 30, 5+ — `0` = навсегда) | 3 |
| `/noclip`, `/clicktp`, `/invis` | noclip, ТП мышкой, невидимость | 3 |
| `/atpm`, `/tpc x y z` | ТП на метку / по координатам | 3 |
| `/aveh модель` | заспавнить машину | 3 |
| `/disarm ID причина` | изъять всё оружие | 3 |
| `/unban номер_бана` или `/unban ник` | разбан | 4 |
| `/agiveitem ID предмет кол-во причина` | выдать предмет | 4 |
| `/agivecar ID модель причина` | машина в гараж (`Config.GiveCarGarage`) | 4 |
| `/asetjob ID работа ранг причина`, `/asetgang …` | работа / банда | 4 |
| `/setleader ID организация причина` | старший (boss) ранг | 4 |
| `/announce текст` | объявление на весь сервер | 4 |
| `/agivemoney ID cash/bank сумма причина`, `/asetmoney …` | рубли; больше 1 000 000 ₽ — нужен `/aconfirm номер` от второго админа 5+ | 5 |
| `/setadmin ID уровень` | назначить / снять админа | 5 |
| `/aresetpin ID` | сбросить PIN | 6 |

из консоли сервера (txAdmin → Live Console) команды работают без смены, например `setadmin 3 6`.

## панель F10
игроки (поиск по нику, имени, ID) → карточка и все действия кнопками; репорты (принять, ТП, закрыть → игрок ставит 1–5 звёзд);
«Я» (noclip, ТП мышкой, на метку, невидимость, вылечиться, PIN); транспорт; объявление; логи с поиском и состав (ур. 5+).
кнопки без прав серые. панель вызывает те же команды, поэтому права и логи проверяет сервер.

## база
таблицы создаются сами при старте ресурса (схема — `sql/2026-11-10_kavkaz_admin.sql`):
`kavkaz_admins`, `kavkaz_admin_log`, `kavkaz_bans`, `kavkaz_warns`, `kavkaz_punish` (мут и недосиженная тюрьма).

## Discord-лог
создать вебхук в закрытом канале и добавить в `C:\kavkaz\secrets.cfg` строку
`set kavkaz_admin_webhook "https://discord.com/api/webhooks/..."`. без неё лог пишется только в базу и консоль.

## проверка
1. `powershell -ExecutionPolicy Bypass -File setup\apply-overrides.ps1`, перезапустить сервер (или `ensure kavkaz_admin`).
2. зайти, `/alogin`, придумать PIN → в чате «Основатель … заступил на смену».
3. F10 → Игроки → себя → Карточка; F2 — noclip; F3 — клик-ТП; `/report тест` → F10 → Репорты.
