# kavkaz_start

первый наш ресурс:
- при **первом входе нового персонажа** — окно «Добро пожаловать» с подсказками и метка GPS на мэрию;
- **/gaid** — открыть подсказку снова (любой игрок);
- **/rename Имя Фамилия** — сменить имя своему персонажу (только `group.admin`);
- **/setname ID Имя Фамилия** — сменить имя персонажу другого игрока (только `group.admin`).

имя: только буквы (кириллица/латиница) и дефис, 2–16 символов.

## установка на сервер (windows)
1. скопировать папку `kavkaz_start` в `C:\kavkaz\txData\Qbox_…base\resources\[kavkaz]\`
2. в `server.cfg` в самый конец (после всех `ensure` qbx/ox):
   ```
   setr ox:locale "ru"
   ensure kavkaz_start
   ```
   `setr ox:locale "ru"` включает русский там, где у ресурсов ox/qbx есть перевод.
3. перезапустить сервер.

тексты приветствия меняются в `config.lua`.
