# kavkaz_start

- при **первом входе нового персонажа** — окно «Добро пожаловать в Нагорск» (3 шага + кнопки) и метка GPS на мэрию.
  окно появляется только когда игрок уже в игре: после выбора квартиры и редактора внешности (ждём, пока закроются все окна);
- **/gaid** — открыть памятку снова (любой игрок);
- **/rename Имя Фамилия** — сменить имя своему персонажу (только `group.admin`);
- **/setname ID Имя Фамилия** — сменить имя персонажу другого игрока (только `group.admin`).

окно — своя страница `html/index.html` в стиле antr5-skill (`C:\kavkaz\SKILL.md`): тёмно-синий, голубой акцент, белые клавиши,
шрифты Montserrat/Onest из лаунчера. предпросмотр в браузере: открыть `html/index.html?preview`.

клавиши в памятке сверены с настройками сервера: TAB инвентарь, ALT взаимодействие (ox_target), M телефон (npwd),
Z быстрое меню (ox_lib), T чат, F1 быстрые слоты (ox_inventory), L замки машины, B ремень, P карта, HOME игроки онлайн.
если меняешь клавиши на сервере — поправь памятку и подсказки экрана загрузки (`kavkaz_loadscreen`).

имя: только буквы (кириллица/латиница) и дефис, 2–16 символов.

## установка

`setup/apply-overrides.ps1` копирует ресурс на сервер, а `overrides/kavkaz.cfg` его запускает (`ensure kavkaz_start`).
