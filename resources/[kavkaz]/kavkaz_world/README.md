# kavkaz_world — облик Нагорья

1. **русские знаки и рекламные щиты.** картинки в `images/` рисует `setup/signs/make_signs.py`
   (знаки «НАГОРСК», конец города, синие и зелёные указатели, 6 щитов: Нагорье Моторс, Хазард 7007, шаурма, чайхана, Нагорье-ТВ, ДПС).
   в игре они подменяют текстуры GTA (`AddReplaceTexture`), файлы игры не трогаем. **чтобы заработало, в `Config.Textures`
   нужно вписать имена текстур GTA** — задание для Claude в VS Code: `docs/tasks/2026-11-11-signs-textures.md`.
   проверить, что картинка загрузилась: `/kvsign city_nagorsk`.
2. **без американской символики:** флаги США, Лос-Сантоса, шерифа скрыты по всей карте (`Config.HideEverywhere`).
3. **посты ДПС** (`Config.Posts`): будка, шлагбаум, конусы, флаг России, прожектор, два инспектора в форме ДПС, УАЗ ДПС.
   первый пост — «Песчаный» (координаты «сверить»: лучше перенести на въезд в город по `/mypos`).
   модель, которой нет в игре, просто пропускается — ошибок не будет.
