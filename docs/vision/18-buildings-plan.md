# 18. Здания и интерьеры: полный план + как делать с Claude в VS Code

Что где стоит, из чего собираем, как это добавить на сервер. Только **бесплатное**. Подборка модов — в [17-map-mods.md](17-map-mods.md).

## Главный вывод поиска
**Готовых российских зданий под GTA 5 (ФСБ, ГИБДД, МРЭО, отдел полиции, панельки) почти нет** — ни на русских сайтах
(libertycity.ru, gtaload, ru.gta5-mods), ни на английских. Русские сайты в основном про GTA San Andreas, а большие русские
RP-проекты (RMRP и др.) рисуют свои карты сами и не выкладывают.

Поэтому схема у нас такая:
1. **здание** — стандартное из GTA (оно уже в игре, бесплатно, без лагов);
2. **интерьер** — из GTA / GTA Online (`bob74_ipl`) или бесплатный MLO;
3. **российский вид** — наши вывески, логотипы и флаги (замена текстур, `.ytd`) + пропы вокруг (флагштоки, шлагбаумы, урны, машины ДПС).

## Автоматизация (готово в репозитории)
| что | файл | что делает |
|---|---|---|
| Нагорье на карте | `resources/[kavkaz]/kavkaz_map` | ~90 районов по-русски, метки всех ведомств, вход в ФСБ (холл FIB), скрытие объектов, папка `stream` |
| страницы модов | `setup/open-mod-pages.ps1` | одной командой открывает страницы 10 бесплатных модов стартового набора и папку `C:\kavkaz\mods-inbox` |
| установка модов | `setup/import-mods.ps1` (на VPS — команда `kavkaz-mods`) | всё из `mods-inbox`: распаковать → проверить на `.exe/.dll` и бэкдоры → собрать ресурс (если мод — просто файлы карты) → `resources\[maps]` → `maps.cfg` с `ensure` → строка `exec maps.cfg` в `server.cfg`. отчёт — `import-log.txt` |

**Дома, по шагам:**
1. `setup\apply-overrides.ps1` — накатить наши ресурсы (в том числе `kavkaz_map`);
2. `setup\open-mod-pages.ps1` — на каждой открывшейся странице нажать Download (на Gumroad ввести цену 0), сохранить в `C:\kavkaz\mods-inbox`;
3. `setup\import-mods.ps1` — всё ставится само;
4. перезапустить сервер и зайти.

Скачивание оставлено ручным намеренно: на сайтах модов кнопки, капчи и рекламные страницы, а скачивать чужие файлы
автоматически без проверки лицензии и безопасности нельзя. Всё остальное делают скрипты.

## Как всё это добавлять с Claude в VS Code

### Что нужно один раз
1. **VS Code** + расширение **Claude Code** (поиск в расширениях: «Claude Code», вход своим аккаунтом Claude).
2. Открыть папку репозитория `C:\project\kavkaz` (**File → Open Folder**). Claude сам прочитает `CLAUDE.md` с правилами проекта.
3. **CodeWalker** — для расстановки объектов и просмотра карты (Claude его не заменяет).
4. Папка для скачанных модов **вне git**: `C:\kavkaz\mods-inbox\` (чужие моды без разрешения автора в репозиторий не кладём).

### Кто что делает
| задача | кто |
|---|---|
| скачать мод, проверить, что он бесплатный у автора | вы |
| распаковать мод в `mods-inbox` и сказать Claude: «посмотри мод X» | вы |
| проверить состав мода: есть ли `fxmanifest.lua`, `stream`, `.ymap`, `.ytyp`, лишние файлы, вирусные `.dll` / `.exe` | **Claude** |
| сделать ресурс по правилам проекта (`kavkaz_map_<имя>`, `fxmanifest.lua`, `ensure` в `kavkaz.cfg`) | **Claude** |
| найти конфликты: два мода в одном месте, одинаковые имена файлов | **Claude** |
| телепорты в интерьеры (вход с улицы → интерьер под картой), двери, метки на карте | **Claude** (код) |
| названия районов и улиц на русском, метки ведомств | **Claude** (код) |
| скрыть ванильное здание по координатам | **Claude** (код) — координаты даёте вы из CodeWalker или игры (`/coords`) |
| расставить объекты, подвинуть здание, сделать двор | **вы в CodeWalker** |
| поправить расстановку текстом | **Claude**: CodeWalker сохраняет `.ymap` в XML — Claude может читать и править координаты, копировать ряды объектов |
| заменить логотипы FIB на ФСБ, вывески | **вы** рисуете картинку (или берёте с разрешения), **Claude** говорит, какие текстуры менять и как собрать `.ytd` |
| проверить на сервере | вы: `ensure ресурс`, F8, присылаете ошибки Claude |

### Как просить Claude (примеры)
```
посмотри мод в C:\kavkaz\mods-inbox\hunt_cabin. он безопасный? сделай из него ресурс kavkaz_map_cabin по правилам проекта
```
```
я поставил избу на 1350.2, 4380.7, 44.1. сделай вход: метка у двери и телепорт внутрь, выход обратно
```
```
переименуй на карте районы по таблице из docs/vision/18-buildings-plan.md и поставь метки всех ведомств
```
```
вот ошибки из F8 после ensure kavkaz_map_ballroom: (вставить текст). в чём проблема?
```
```
вот ymap в XML (C:\kavkaz\mods-inbox\bazaar.ymap.xml). продублируй ряд прилавков ещё на 10 метров вдоль улицы
```

### Порядок работы над одним зданием
1. **выбрать** здание и интерьер по таблицам выше;
2. **скачать** мод (если нужен) → `mods-inbox`;
3. **Claude**: проверка + ресурс + `ensure`;
4. **запустить** сервер, зайти, посмотреть;
5. **CodeWalker**: декор, вывески, пропы вокруг → сохранить `.ymap` в ресурс;
6. **Claude**: телепорт, метка, NPC, работа/скрипт для этого места;
7. **закоммитить** (Claude сделает коммит, если попросить) и отметить в таблице «Установленные моды» в 17-map-mods.md.

### Чего Claude не может
- видеть игру и CodeWalker: всё, что «на глаз», делаете вы, а Claude помогает по скриншотам и координатам;
- редактировать бинарные `.ymap`, `.ydr`, `.ytd` напрямую — только XML-версии из CodeWalker;
- рисовать текстуры и 3D-модели.

## С чего начать на этой неделе
1. проверить, что `bob74_ipl` стоит, и включить холл FIB;
2. попросить Claude сделать **`kavkaz_map`**: русские названия районов, метки всех ведомств из таблицы, вход в ФСБ;
3. поставить **Hunt Cabin** по порядку выше — первая проверка всей цепочки;
4. сделать логотип **ФСБ** вместо FIB (по примеру retexture).
