## Три правила проекта

1. **Без риска.** Никаких чужих брендов, чужих логотипов и украденных модов. Донат только косметический, без платных случайных кейсов (это запрещают правила Cfx.re). Кавказ показываем с уважением: гостеприимство, юмор, горы, семья. Никаких стереотипов «кавказец = бандит».
2. **Сначала готовое, потом своё.** Qbox уже даёт деньги, работы, инвентарь, телефон. Поверх него добавляем ресурсы `kavkaz_*`.
3. **Новичку должно быть тепло.** Первые 30 минут игры решают, останется человек или нет.

## Сеттинг

Действие идёт в вымышленной **Республике Нагорье**. Карта — это Лос-Сантос из GTA V, но в лоре у мест свои имена:

| в GTA | у нас |
|---|---|
| Лос-Сантос | город **Нагорск**, столица республики |
| Блэйн-Каунти, Сэнди-Шорс | **Степной район**, посёлок **Песчаный** |
| Палето-Бэй | **аул Палето**, рыбацкое село на севере |
| гора Чилиад | **гора Чилиад-Тау**, место паломничества тюнингованных Нив |
| аэропорт LSIA | **Аэропорт «Нагорск-Международный»** |
