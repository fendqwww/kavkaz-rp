# 12. Интерфейс

## Стиль
- тёмно-синий фон, как ночное горное небо; золотой акцент; белый текст;
- тонкий орнамент на рамках меню (едва заметный);
- современный читаемый шрифт с кириллицей;
- **весь интерфейс на русском**, суммы в рублях с пробелами: `1 250 000 ₽`.

## HUD
- слева внизу: здоровье, броня, голод, жажда, стресс (круглые иконки);
- справа вверху: наличные и карта в ₽, ID, время и погода в Нагорске;
- в машине: спидометр, топливо (с типом: бензин/газ), ремень, круиз, индикатор СГУ и музыки;
- голос: кто тебя слышит (шёпот, обычно, крик);
- значок уважения рядом с именем в меню игрока.

## Телефон «Нагорье-Фон»
| приложение | что делает |
|---|---|
| звонки, SMS, контакты | связь |
| **«Горграм»** | фото, лайки, подписчики |
| **«Кавказ-Чат»** | общий чат города |
| **Банк** | переводы, кредиты, налоги |
| **Такси** | вызов живых таксистов |
| **Авито-аналог «Базар»** | объявления: продам, куплю, сдам |
| **Карта** | метки, маршрут |
| **Задания** | квесты, ежедневки, батл пасс |
| **Новости** | статьи СМИ |
| **Свадьбы** | заказ у «Салманова Event», приглашения гостям, список гостей |
| **Госуслуги-аналог «Республика»** | штрафы, документы, запись в автошколу, разрешение на кортеж |
| **Музыка** | радио «Нагорье-FM» и свои треки |
| **Камера** | селфи, фото, режим фото |

## Меню
- **радиальное меню** (колесо): действия с собой, машиной, домом;
- **ox_target:** навёл на объект — выбрал действие;
- **меню эмоций:** анимации, стили ходьбы, лезгинка, совместные действия;
- **меню машины:** СГУ, музыка, аварийки кортежа, флаг в окно, высунуться;
- **админ-панель** (F10, только админам).

## Анимации и ходьба
- **стили ходьбы:** обычный, уверенный, деловой, вальяжный, «Как Румиса» (величавый), спортсмен, усталый, пьяный (для RP);
- **эмоции:** лезгинка (несколько вариантов), тост, обнять, рукопожатие, прижать руку к сердцу (приветствие), чётки, пить чай из стакана-армуды, махать флагом, сидеть на корточках, звонить, фотографировать;
- **совместные:** обнять, пожать руку, поднять тост вместе, танец пары.

## Звук
- музыка загрузки;
- радио в машине: «Нагорье-FM» (кавказская эстрада), «Горы-Рок», «Чилл»;
- звуки СГУ (несколько мелодий);
- озвучка ключевых фраз NPC.
