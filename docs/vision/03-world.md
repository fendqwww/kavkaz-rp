# 03. Город и интерьеры

Где всё это стоит на карте GTA и как ставить моды карт — в [10-map.md](10-map.md).

## Районы Нагорска
| район | что там |
|---|---|
| **Центр** | правительство, банк, мэрия, площадь для митингов и праздников |
| **Старый город** | рынок «Восточный базар», чайхана, мастерские, узкие улочки |
| **Набережная** | кафе, кальянные, прогулки, место для свиданий |
| **Промзона** | склады, работа грузчиком и водителем, СТО |
| **Нагорск-Сити** | бизнес-центр, офисы, дорогие квартиры |
| **Посёлок Песчаный** | дальнобойщики, заправки, байкеры |
| **Аул Палето** | рыбалка, фермы, пасека, сыроварня |
| **Чилиад-Тау** | горы, туризм, канатка, горный пост МЧС, шашлычная на вершине |

## Интерьеры (MLO)
Берём бесплатные или купленные с лицензией MLO и перекрашиваем под наш стиль: вывески на русском, ковры, чайные сервизы, флаги республики.

| место | что внутри |
|---|---|
| **Больница** | приёмный покой, палаты, операционная, рентген, кабинет главврача, вертолётная площадка на крыше |
| **ГУ МВД** | дежурная часть, камеры, комната допросов, оружейная, гараж, тир |
| **Управление ФСБ** | пропускной пункт, оперативный штаб с картой, архив, комната переговоров, подземный гараж |
| **Пожарная часть МЧС** | гараж с пожарными машинами, столовая, спортзал |
| **Правительство** | зал заседаний, кабинет губернатора, приёмная, архив законов |
| **Телецентр** | студия новостей, радиорубка, монтажная |
| **Дома и квартиры** | от «однушки в панельке» до коттеджа с садом и дома в горах с камином; мебель можно расставлять самому |
| **Чайхана «У Румисы»** | столовая, кухня, задний двор с мангалом — точка старта квестов |
| **Лаборатория Исы Хамидовича** | химическая лаборатория при университете, столы с колбами, вытяжка, аптека «Формула» рядом |
| **Военная часть** | КПП, казарма, склад, плац, ангар |
| **Тюрьма** | камеры, двор, столовая, работа для заключённых |

## Будки и точки на карте
- **Шаурма и хачапури** — ларьки по городу, можно купить еду или устроиться работать продавцом.
- **Киоск «Союзпечать»** — газеты СМИ, лотерейные билеты за игровые деньги.
- **Будка ДПС** на въездах в город — пост для полиции.
- **Пост «Горный патруль»** МЧС у подножия гор.
- **Банкоматы** — снятие и пополнение счёта.
- **Таксофоны** — позвонить, если сел телефон.
- **Автобусные остановки** — работа водителем автобуса, бесплатный проезд для новичков.
- **Колонки с родниковой водой** в горах — бесплатная вода, снимает жажду.
