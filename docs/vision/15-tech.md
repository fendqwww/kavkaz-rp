# 15. Технические основы

## Лаунчер «KAVKAZ RP»

### Что видит игрок
1. Скачивает с сайта или из Discord один файл `KAVKAZ-RP-Setup.exe` (~10 МБ).
2. Устанавливает и открывает лаунчер. Тот сам проверяет компьютер и показывает чек-лист:
   - ✅ Windows 10/11 64-бит
   - ✅ GTA V найдена (Steam / Epic / Rockstar)
   - ⏳ FiveM — устанавливается…
   - ⏳ Системные библиотеки — устанавливаются…
3. Когда всё зелёное, большая кнопка **«Играть»** запускает FiveM и сразу подключает к серверу.
4. Дальше лаунчер просто открывается, показывает онлайн и новости, и игрок жмёт «Играть».

### Экран лаунчера
- фон: горы и огни Нагорска (как на загрузке), логотип;
- **«Играть»**, рядом онлайн «128 / 200» и статус сервера (работает / рестарт / техработы);
- новости и обновления (карточки с картинками);
- кнопки: Discord, правила, донат, сайт;
- настройки: режим для слабых ПК, путь к GTA, язык, «переустановить FiveM»;
- внизу версия лаунчера.

### Что делает лаунчер внутри
| задача | как |
|---|---|
| проверка системы | версия Windows, разрядность, память, видеокарта, свободное место (через системные запросы Windows) |
| **найти GTA V** | реестр Rockstar Games, файлы Steam (`libraryfolders.vdf`, игра 271590), манифесты Epic Games. Если не найдена — кнопка «Указать папку» и ссылки на покупку |
| **найти FiveM** | `%LOCALAPPDATA%\FiveM\FiveM.exe` |
| **поставить FiveM** | скачать официальный установщик с сервера FiveM и запустить. Сами файлы FiveM мы не раздаём (это запрещено их лицензией) — только официальный установщик |
| **поставить библиотеки** | Visual C++ Redistributable x64 (официальная ссылка Microsoft, тихая установка `/install /quiet /norestart`), DirectX Runtime, проверка .NET |
| **статус сервера** | у сервера FiveM есть адреса `/info.json`, `/players.json`, `/dynamic.json` — оттуда онлайн и статус |
| **новости** | файл `news.json` в нашем GitHub или на сайте. Новость добавили — у всех обновилось |
| **адрес сервера** | тоже берётся из файла настроек в интернете. Переехали на VPS — лаунчер переподключится сам, переустанавливать не надо |
| **«Играть»** | открывает ссылку `fivem://connect/адрес` |
| **режим для слабых ПК** | делает резервную копию и правит `Документы\Rockstar Games\GTA V\settings.xml` (дальность, трава, тени). Плюс в игре — переключатель в нашем меню |
| **автообновление** | при запуске проверяет новую версию на GitHub Releases и обновляется сам |

### Чего лаунчер не делает
- **не ставит GTA V** (её покупают);
- **не входит в аккаунт Cfx.re за игрока** (FiveM попросит войти при первом запуске);
- **не скачивает заранее файлы сервера** — FiveM делает это сам при первом заходе;
- **не античит.** Защита от читов — на сервере.
- **не собирает личные данные:** никаких паролей, логинов, файлов игрока.

### На чём делаем
**Tauri** (Rust + веб-интерфейс): лаунчер весит ~10 МБ против ~100 МБ у Electron и быстрее запускается. Интерфейс — HTML/CSS/JS, как и все интерфейсы в игре.

**Сборка:** автоматически через GitHub Actions на Windows-машине GitHub. Сделали изменения → GitHub сам собирает `.exe` и выкладывает в Releases. Тебе не нужно ничего ставить.

### Цифровая подпись и антивирусы
- без подписи Windows покажет «Неизвестный издатель» → «Подробнее» → «Выполнить»;
- программы, которые скачивают и запускают другие установщики, иногда пугают антивирусы. Поэтому: качаем только с официальных адресов FiveM и Microsoft, отправляем каждую версию в Microsoft на проверку (бесплатно), в будущем покупаем подпись;
- для открытых проектов есть бесплатные варианты подписи (например, SignPath Foundation) — проверим, подходим ли.

### Этапы
1. **v0.1 (с играбельной версией, 2–3 часа):** проверка GTA и FiveM, кнопка «Играть», онлайн.
2. **v0.5 (к закрытому тесту):** автоустановка FiveM и библиотек, новости, режим для слабых ПК.
3. **v1.0 (к открытию):** дизайн, автообновление, настройки, ссылки, проверка системы.

## Сервер: где и как будет жить

### Сейчас: твой компьютер
Для разработки и игры с друзьями. Минус: сервер работает, только пока включён твой ПК.

### Потом: VPS (арендованный сервер)
| параметр | на 50–100 игроков | на 200+ игроков |
|---|---|---|
| процессор | 4–6 ядер, высокая частота | 8+ ядер |
| память | 16 ГБ | 32 ГБ |
| диск | NVMe, 100 ГБ | NVMe, 200 ГБ |
| сеть | защита от DDoS обязательна | то же |
| ОС | Windows Server или Linux | Linux |

Ориентир по цене — несколько тысяч рублей в месяц. Переезд: копируем `txData`, базу и `secrets.cfg`, меняем адрес в настройках лаунчера.

### Два сервера: рабочий и тестовый
- **тестовый** (у тебя на ПК): сюда ставим всё новое и проверяем;
- **рабочий** (VPS): только проверенное.
Так игроки не увидят сломанные обновления.

## Код и обновления
- весь наш код — в GitHub (`fendqwww/kavkaz-rp`), ветка `main` — рабочая, новое — в ветках `feature/...`;
- свои ресурсы — `resources/[kavkaz]/kavkaz_*`;
- изменения базы — файлы `sql/дата_что.sql`;
- **секреты (пароли, ключи) — никогда в GitHub**, только в `C:\kavkaz\secrets.cfg`;
- **платные моды — не в GitHub** (лицензия), только список.

## База данных и бэкапы
- MariaDB, база `qbox`;
- **автобэкап раз в сутки** + перед каждым обновлением;
- хранить 14 последних копий, раз в неделю — копия на другой диск или в облако;
- откат имущества игрокам — из логов и бэкапов.

## Discord
- **бот сервера:** онлайн в статусе, новости, привязка Discord к аккаунту в игре, роли (админ, лидер, медиа);
- каналы: новости, правила, заявки в организации, жалобы, жалобы на админов, обращения, логи админов (закрытый), баги, предложения;
- **вход только с привязанным Discord** (защита от твинков и читеров).

## Производительность
- каждый наш ресурс проверяем командой `resmon` в F8: в простое — не больше 0,05 мс;
- машины — не больше 20–30 МБ, текстуры сжаты;
- первая загрузка сервера — не больше 1,5 ГБ;
- режим для слабых ПК на стороне сервера (меньше машин и NPC).

## Защита
- все деньги, предметы и права проверяются **на сервере**, клиенту не доверяем;
- SQL — только с параметрами (`?`), без склейки строк;
- логи всех админ-действий;
- лимиты на частоту событий (защита от спама и эксплойтов);
- защита от DDoS на VPS.
