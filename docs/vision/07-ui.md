# 07. Интерфейс, телефон, ходьба

## Общий стиль
- Цвета: тёмно-синий горный фон, золотой акцент (как вышивка), белый текст.
- Узоры: тонкий кавказский орнамент на рамках меню.
- Шрифт: современный, хорошо читается на русском.
- **Весь интерфейс на русском.**

## HUD (то, что на экране)
- Внизу слева: здоровье, броня, сытость, жажда, стресс (маленькие круглые иконки).
- Сверху справа: деньги, ID игрока, время и погода в Нагорске.
- В машине: спидометр, топливо, ремень безопасности, круиз-контроль.
- Голос: значок микрофона, кто вас слышит (шёпот, обычно, крик).

## Телефон «Нагорье-Фон»
На основе npwd, переделанный под наш стиль.
| приложение | что делает |
|---|---|
| Звонки, SMS, контакты | обычное общение |
| **«Горгрант»** (аналог Instagram) | фото, лайки, подписчики |
| **«Кавказ-Чат»** | общий чат города |
| **Банк** | переводы, история операций, налоги |
| **Такси** | вызов такси, где таксисты — живые игроки |
| **Объявления** | продам «Приорку», куплю дом, ищу работу |
| **Карта** | метки, маршрут |
| **Задания** | квесты Румисы и других NPC, ежедневки, батл пасс |
| **Новости** | статьи СМИ «Нагорье-ТВ» |
| **Знакомства** | для RP-свиданий |
| **Музыка** | радио «Нагорье-FM» |

## Ходьба и анимации
- **Стили ходьбы** (выбираются в меню эмоций): «Обычный», «Уверенный», «Деловой», «Вальяжный», «Бабушкин», «Как Румиса» (неспешный и величавый), «Спортсмен», «Пьяный» (для RP).
- **Эмоции:** лезгинка, тост с бокалом, обнимашки, рукопожатие, помахать, сесть на корточки, чётки в руке, чай из армуды.
- **Совместные анимации:** обнять, пожать руку, поцеловать в щёку (с согласия второго игрока).

## Меню
- **Радиальное меню** (колесо): действия рядом с игроком, машиной, домом.
- **Меню взаимодействия** через ox_target: навести на объект, выбрать действие.
- **Пятно на карте** вместо длинных меню, где возможно.

## Звук
- Своя музыка загрузочного экрана.
- Радиостанции в машине: «Нагорье-FM» (кавказская эстрада), «Горы-Рок», «Чилл-Тау».
- Озвучка ключевых фраз NPC (Румиса, Рустам).
