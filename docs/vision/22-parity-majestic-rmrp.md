# 22. Догоняем Majestic и RMRP: чаты, механики, интерфейс

Основатели хотят уровень Majestic RP и RMRP. Файл собран по скриншотам, которые прислал основатель 10.11.2026
(лаунчер и HUD Majestic, меню взаимодействия, банк, заправка, обмен машинами, навыки, автосалон, HUD и чат RMRP).
Что у них есть по скринам — факт. Чего на скринах нет — помечено «по памяти, проверить».

Правило: делаем **макет → основатель выбирает → код**. Ни одно окно не идёт в игру без «да» основателя.

## 1. Общий стиль (из примеров)

| у них | у нас сейчас | делаем |
|---|---|---|
| почти чёрный нейтральный фон (#141414–#1a1a1a), **один** яркий цвет (у Majestic малиновый, у RMRP зелёный) | тёмно-зелёный фон, изумруд + золото, свечения | нейтральный чёрный, один цвет — изумруд, золото только для денег |
| углы 4–8 px, без свечений, тонкие разделители | «пузыри», свечения, рамки | острее, без свечений |
| крупный текст, плотные данные, заголовки капсом | текст 11–12 px, пустые коробки | основной текст 15–16 px при 1080p |
| HUD без рамок, текст с тенью прямо на картинке | плашки, мелкие кружки | как у них |
| один логотип везде | три разных логотипа | один |
| шрифт Gilroy (платный) | Manrope | заголовки Unbounded, текст — подобрать на макете |

## 2. Чат

| у них (по скринам) | у нас | делаем |
|---|---|---|
| **цветная метка типа** перед строкой: «Действия», «Рядом», «Рация» и т. д. (RMRP) | цвет текста, без меток | метки: Рядом, Крик, Шёпот, Действие, Окружение, Попытка, NonRP, Рация, Департамент, Семья, Гос, Админ, Объявление |
| **статический ID** игрока в строке: «Егор Иваньков 456-515» (RMRP), «#33246» (Majestic) | серверный ID меняется при каждом входе | постоянный номер аккаунта (выдаётся один раз), в чате, F4, табе и HUD |
| **автодействия**: «снял с ручного тормоза», «пристегнул ремень», «заглушил т/с», «надел лёгкий бронежилет» сами пишутся в чат | нет | автодействия на ремень, двигатель, двери, оружие, броню, рацию, камеру, еду |
| время у строки (RMRP «06:51:57 Рядом») | нет | время по желанию (настройка) |
| объявления в виде карточки с автором и редактором (Majestic «Weazel News») | нет | «Нагорье-ТВ: объявления» — игрок подаёт, редактор СМИ одобряет, карточка у всех |
| вкладки/фильтры чата, прозрачность, размер (по памяти, проверить) | нет | вкладки: Всё, IC, NonRP, Рация, Админ; размер и прозрачность в настройках |

## 3. HUD

| у них | у нас | делаем |
|---|---|---|
| слева внизу у миникарты: время, дата, день недели, погода, район и улица, наличные и карта (Majestic) | похоже, но мелко | крупнее, без плашек, + **улица** (сейчас только район) |
| справа сверху: лого, онлайн, номер сервера, ID и статический ID | лого + онлайн | + статический ID |
| справа столбик подсказок клавиш: Телефон, Инвентарь, Взаимодействие, Меню F2, Навигатор F3, Голос, Скрыть подсказки F6 | 3 подсказки | полный столбик, скрывается клавишей |
| спидометр: передача в белом квадрате, крупные цифры, пробег, оборот, топливо, лампы (Majestic), «001» наклонные (RMRP) | круговой, мелкий | **макет готов**: варианты «барабан» и «табло» (перелистывание), выбор за основателем |
| **компас-лента** внизу экрана с градусами (RMRP) | нет | лента-компас над миникартой |
| значок **«Безопасно»** в зелёной зоне (Majestic) | нет | зелёные зоны: больница, мэрия, мечеть, автовокзал |
| карточки уведомлений с кнопками **Принять / Отклонить** (RMRP) | ox_lib уведомления | свои карточки: приглашения в организацию, сделки, вызовы |
| виджет заданий справа с кнопкой «Забрать награду» (RMRP «Боевой пропуск») | нет | ежедневные задания (см. 4) |
| награда за онлайн: «сыграй 5 часов — получи 200 коинов» с таймером (Majestic) | нет | бонус за время в игре (в ₽ или очках сезона, без доната силы) |
| счётчик очков дрифта по центру (Majestic) | нет | дрифт-зона Аминат (этап 6) |

## 4. Механики

| у них | у нас | делаем, приоритет |
|---|---|---|
| **меню взаимодействия** кнопками вокруг центра: Багажник, Капот, Бардачок, Ремень, Мегафон, Зажигание, Высадить, Ещё (Majestic), двери по отдельности (RMRP) | ox_target (ALT, список) | своё радиальное меню на G для машины и игрока — **высокий** |
| **меню игрока F2**: Персонаж (основное, статистика, транспорт, имущество, навыки), Анимации, Задания, Обращения, Магазин, Мини-игры, Игровая статистика, Правила, Настройки (Majestic) | F4: Профиль, Статистика, Безопасность, Промокод, Реферал, Настройки, Помощь | добавить: Транспорт, Имущество, Навыки, Анимации, Задания, Обращения, Правила — **высокий** |
| **навыки** с прогрессом: выносливость, сила, стрельба, вождение; профессии с рангами (лесоруб, рыболов, дальнобойщик, мусорщик, водитель автобуса…) | нет | навыки + ранги работ — **средний** |
| **обмен машинами** между игроками: карточки обеих машин, пробег, состояние, тюнинг, доплата, налог, двойное подтверждение (Majestic) | нет | обмен и продажа машин игроку с проверкой на сервере — **средний** |
| **состояние машины** по узлам (двигатель, тормоза, подвеска… в %), **пробег**, тип топлива (Majestic) | нет | пробег и износ, ремонт в СТО — **средний** |
| **заправка**: виды топлива, литры ползунком, наличные/карта, товары (аккумулятор, канистра, инструменты) (Majestic) | стандартная | своя заправка в ₽ — **средний** |
| **автосалон**: список слева, машина в зале, характеристики, цвет, тест-драйв, комплекты обвесов (Majestic) | kavkaz_cars: салон «Нагорье Моторс» | переделать окно по образцу — **средний** |
| **банк**: тарифы счёта с кэшбэком и комиссией (Majestic) | стандартный | банк «Нагорье-Банк», тарифы — **низкий** |
| **боди-камера** с записью (RMRP) | нет | для МВД/ДПС — **низкий** |
| **спецодежда** по работам (Majestic) | частично (форма ДПС/ФСБ на NPC) | одежда организаций — уже в плане 20 |
| задания и сезонный пропуск (RMRP, Majestic) | нет | ежедневные задания + сезон с честными наградами — **средний** |

## 5. Порядок (по одному, каждый — макет, выбор, код, проверка на VPS)

1. Спидометр (макет готов, ждёт выбора А/Б).
2. HUD целиком: левый низ, правый верх, столбик подсказок, компас-лента.
3. **Чат**: метки типов, постоянный ID, автодействия, время, вкладки.
4. Меню взаимодействия G (машина и игрок).
5. Уведомления-карточки с «Принять / Отклонить».
6. Меню игрока F2/F4 по образцу Majestic: новые разделы.
7. Обмен машинами и состояние/пробег.
8. Задания дня, бонус за онлайн, навыки.
9. Заправка, автосалон, банк.
10. Объявления «Нагорье-ТВ».
