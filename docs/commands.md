# Команды KAVKAZ RP

Шпаргалка по тому, что можно написать в чат (клавиша **T**). Составлена по описаниям ресурсов в репозитории (README каждого ресурса). В игре проверено не всё: если команда не работает, пришли скрин ошибки.

Уровни админов: 1 — помощник, 2 — админ, 3 — старший, 4 — куратор, 5 — главный, 6 — основатель.

## Любой игрок

| команда | что делает |
|---|---|
| `/gaid` | памятка новичка: с чего начать и какие кнопки |
| `/report текст` | написать администрации (раз в минуту) |
| `/pay ID сумма` | передать наличные игроку рядом (до 3 м) |
| `/fines` | свои неоплаченные штрафы, оплата с карты |
| `/me текст` | действие персонажа (от Qbox) |
| `/ooc текст` | общий чат вне игры (от Qbox) |

## Чаты

| команда | что делает | кто видит |
|---|---|---|
| обычный текст | речь персонажа | рядом, 15 м |
| `/s текст` | крик | 40 м |
| `/w ID текст` | шёпот (вплотную) | один игрок |
| `/do текст` | описание обстановки | рядом |
| `/try текст` | попытка: «удачно» или «неудачно» (50/50) | рядом |
| `/todo фраза*действие` | «Привет», — сказал Ахмед, пожимая руку | рядом |
| `/b текст` | локальный нон-РП | рядом |
| `/pm ID текст` | личное нон-РП сообщение | один игрок |
| `/r текст`, `/rn текст` | рация организации: в роли (IC) и вне роли (NonRP). У госструктур только на смене | своя работа |
| `/d текст` | департамент (МВД, ФСБ, больница, МЧС на смене) | госструктуры |
| `/f текст`, `/fn текст` | семья или банда: в роли и вне роли | своя банда |
| `/gov текст` | госновости (ранг boss госструктуры) | весь сервер |

Если админ замутил игрока (`/mute`), у него отключаются все чаты и голос.

## Полиция и ДПС (на смене)

| команда | что делает |
|---|---|
| `/fine [ID]` | выписать штраф: статья, сумма (не выше потолка статьи), описание |
| `/checkplate номер` | пробить номер: владелец, неоплаченные штрафы |

Штраф через 3 дня удваивается (один раз). После оплаты 10% идёт инспектору.

## Номера (админам)

| команда | что делает |
|---|---|
| `/setplate` | выдать или поменять номер машине, в том числе красивый |
| `/issueplate` | выдать номер игроку |
| `/setframe номер текст` | поставить рамке свою надпись |

Обычный игрок получает номер в МРЭО у окна NPC по паспорту.

## Вход админа

| команда | что делает |
|---|---|
| `/alogin` | заступить на смену. Первый раз придумываешь PIN из 6 цифр |
| `/alogout` | сдать смену |
| `/apin` | сменить PIN |
| `/apanel` или **F10** | админ-панель |
| **F2** | полёт (noclip): WASD, Q/E вверх и вниз, SHIFT быстрее |
| **F3** | телепорт мышкой: ЛКМ перенестись, ПКМ выйти |

Без смены админ-команды не работают, даже у основателя. Три неверных PIN блокируют вход на 15 минут.

## Админ-команды по уровням

| ур. | команды |
|---|---|
| 1 | `/goto ID`, `/bring ID`, `/spec ID`, `/a текст` (админ-чат), `/admins` (кто на смене) |
| 2 | `/kick ID причина`, `/mute ID минуты причина`, `/unmute ID`, `/ajail ID минуты причина`, `/unjail ID`, `/warn ID причина`, `/arevive [ID]`, `/freeze ID`, `/check ID`, `/afix`, `/aflip`, `/adv [радиус]` |
| 3 | `/ban ID дни причина`, `/noclip`, `/clicktp`, `/invis`, `/atpm`, `/tpc x y z`, `/aveh модель`, `/disarm ID причина` |
| 4 | `/unban номер`, `/agiveitem ID предмет число причина`, `/agivecar ID модель причина`, `/asetjob ID работа ранг причина`, `/asetgang`, `/setleader ID организация причина`, `/announce текст` |
| 5 | `/agivemoney`, `/asetmoney` (больше 1 000 000 ₽ нужно подтверждение второго админа: `/aconfirm номер`), `/setadmin ID уровень` |
| 6 | `/aresetpin ID` |

Три предупреждения (`/warn`) дают бан на 3 дня. Бан: уровень 3 до 7 дней, уровень 4 до 30, уровень 5 и выше любой срок.

## Основатель

Основатели (уровень 6) имеют все права. Назначить друга основателем: `/setadmin ID 6` в игре или `setadmin ID 6` в консоли txAdmin.

## Служебное

| команда | что делает |
|---|---|
| `/mypos` | скопировать свои координаты (для настройки карты) |
| `/rename Имя Фамилия` | сменить имя своему персонажу (админы) |
| `/setname ID Имя Фамилия` | сменить имя персонажу игрока (админы) |
