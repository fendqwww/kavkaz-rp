# сервер на VPS (Linux) — от покупки до игры

боевой сервер KAVKAZ RP живёт на VPS. всё ставится тремя командами, руками править файлы не нужно.

## 1. купить VPS
- хостинг: H1Cloud (или любой другой — шаги те же);
- ОС: **Ubuntu 22.04 или 24.04** (Debian 12 тоже подойдёт). Windows на VPS не ставим;
- тариф: самый старший из доступных. ориентир: 4+ ядра, 8–16 ГБ памяти, диск 40+ ГБ;
- минимум, на котором сервер вообще запустится: 4 ГБ памяти, 10 ГБ диска.
  с диском меньше 40 ГБ моды карты не поместятся;
- после покупки хостинг пришлёт **IP, логин `root` и пароль**. пароль никому не пересылать.

## 2. зайти на VPS
на ПК открыть PowerShell и набрать (IP — свой):
```
ssh root@IP
```
спросит пароль — ввести (символы не показываются, это нормально).

## 3. поставить сервер — одна команда
```
curl -fsSL https://raw.githubusercontent.com/fendqwww/kavkaz-rp/claude/zen-allen-mjpj7c/setup/install-linux.sh | bash
```
скрипт сам: проверит железо, поставит базу MariaDB, скачает FiveM, включит автозапуск, файрвол и ежедневный бэкап базы,
скачает наш код. в конце покажет адрес txAdmin и PIN.

если скрипт остановился с красной «Ошибка: …» — там написано, чего не хватает (обычно процессор или память тарифа).

## 4. txAdmin — рецепт Qbox
1. открыть в браузере `http://IP:40120`, ввести PIN, войти через аккаунт Cfx.re;
2. **Popular Recipes → Qbox**;
3. база данных: host `127.0.0.1`, port `3306`, user `kavkaz`, имя базы `qbox`.
   пароль базы: на VPS команда `cat /opt/kavkaz/secrets.cfg` (строка `mariadb_kavkaz_password`);
4. ключ сервера: создать новый на https://portal.cfx.re для IP этого VPS и вставить в txAdmin;
5. дождаться конца установки и один раз запустить сервер.

## 5. поставить наши ресурсы — одна команда
```
kavkaz-update --restart
```
ставит админку, номера, квесты, штрафы, чат, карту, перевод и тему интерфейса, потом перезапускает сервер.
таблицы в базе создаются сами при запуске.

## 6. первый вход
- в игре: F8 → `connect IP`;
- себя сделать основателем: txAdmin → Players → себя → дать права admin (группа `group.admin`); в игре `/alogin`;
- лаунчер: прислать IP (или домен) — адрес вписывается в `launcher/config.json`, лаунчер подхватит сам.

## если VPS уже работает (наш — 13.141.51.196)
сервер уже стоит, заново ничего ставить не надо. чтобы на нём появились команды `kavkaz-update` и `kavkaz-mods`,
один раз запусти ту же команду из шага 3 — она пропустит всё, что уже сделано, и только добавит наш код и команды.
дальше вместо `/root/deploy-vps.sh` — `kavkaz-update --restart`.

## дальше: обновления
всё новое из GitHub ставится той же командой:
```
kavkaz-update --restart
```
- старые версии заменённых файлов лежат в `/opt/kavkaz/backup-overrides/<дата>/`;
- поставить другую ветку: `kavkaz-update --branch имя-ветки --restart` (запоминается).

## моды карты
1. закинуть архивы (`.zip`, `.7z`, `.rar`) с ПК на VPS в папку `/opt/kavkaz/mods-inbox`:
   - программой **WinSCP** (вход: IP, `root`, пароль) — перетащить файлы мышкой;
   - или из PowerShell: `scp .\мод.zip root@IP:/opt/kavkaz/mods-inbox/`;
   - или дать прямую ссылку на архив: `kavkaz-mods https://.../мод.zip`;
2. на VPS: `kavkaz-mods --restart`.

скрипт распакует, проверит на вредный код (`.exe`, скрипты-бэкдоры — такие моды не ставит), соберёт ресурсы в
`resources/[maps]` и подключит. отчёт: `/opt/kavkaz/mods-inbox/import-log.txt`.

## машины
модели машин в git не лежат (`resources/[cars]`, их собирает `setup/cars/build.py` на ПК).
на VPS их закидывают в папку сервера `resources/[cars]` (WinSCP или `scp -r`), потом `kavkaz-update --restart`:
команда сама пишет `cars.cfg` и ставит `ensure kavkaz_cars` перед `qbx_core`.

## секреты
- файл `/opt/kavkaz/secrets.cfg` есть только на VPS: пароль базы, а также всё, что допишем (вебхук Discord:
  `set kavkaz_admin_webhook "..."`);
- в git, в чат и в скриншоты его содержимое не попадает.

## шпаргалка
| что | команда |
|---|---|
| обновить наш код | `kavkaz-update --restart` |
| поставить моды | `kavkaz-mods --restart` |
| перезапустить сервер | `systemctl restart kavkaz` |
| остановить | `systemctl stop kavkaz` |
| смотреть консоль | `journalctl -u kavkaz -f` (выход — Ctrl+C) |
| бэкап базы сейчас | `kavkaz-backup` (лежат в `/opt/kavkaz/backups`, 14 штук) |
| забрать бэкапы на ПК | в PowerShell на ПК: `scp root@IP:/opt/kavkaz/backups/* .` |
| сколько места на диске | `df -h /` |

## переезд на другой VPS
1. на старом: `kavkaz-backup`, забрать файл из `/opt/kavkaz/backups` на ПК;
2. на новом: шаги 2–5;
3. залить базу: `zcat qbox_ДАТА.sql.gz | mariadb` (под root на новом VPS), `systemctl restart kavkaz`;
4. вписать новый IP в `launcher/config.json` (если есть домен — поменять только запись у домена).
