## 1. Светофоры: перекрасить американские в российские (без новых моделей)
У GTA светофоры жёлто-чёрные американские. Российский — чёрный или тёмно-серый корпус, круглые линзы, чёрный экран за линзами
с тонкой белой каймой. Работу светофоров (переключение) не трогаем — меняем только текстуры корпуса и экрана.
1. CodeWalker → RPF Explorer → найти модели `prop_traffic_01a`, `prop_traffic_01b`, `prop_traffic_01d`, `prop_traffic_02a`,
   `prop_traffic_02b`, `prop_traffic_03a`, `prop_traffic_03b`, `prop_traffic_lightset_01` (если есть) и их словари текстур
   (имя `.ytd` видно в свойствах модели / в `.ytyp`).
2. Выгрузить `.ytd` → `python -I setup\retex\ytd_export.py <папка> C:\kavkaz\mods\retex\out_lights` → посмотреть `sheet.html`.
3. Текстуры корпуса и козырьков перекрасить в тёмно-серый `#2b2d2f` (жёлтое → тёмное, сохранить потёртости и тени),
   экран за линзами — чёрный с белой каймой. Скрипт перекраски сделать в `setup/retex/recolor_lights.py`
   (оттенок/насыщенность через numpy, не рисовать заново). Результат — в `kavkaz_world/images/local/`, строки — в `Config.Textures`.
4. Проверить днём и ночью: линзы светятся, переключение работает.

## 2. Американские знаки на столбах → наши
1. CodeWalker → найти знаки `prop_sign_road_01a` … `prop_sign_road_09f` (и похожие), выгрузить их `.ytd`, `ytd_export.py`.
2. Сопоставить:

| американский | наш |
|---|---|
| STOP (восьмиугольник) | `gost_2_5` |
| YIELD | `gost_2_4` |
| DO NOT ENTER / WRONG WAY | `gost_3_1` |
| SPEED LIMIT 25/35/45/55… | `gost_3_24_40` в городе, `gost_3_24_60`/`gost_3_24_90` на трассах |
| NO PARKING | `gost_3_28` |
| ONE WAY (стрелка) | `gost_4_1_2` / `gost_4_1_3` |
| PED XING | `gost_5_19_1` (у перехода) или `gost_1_22` (заранее) |
| KEEP RIGHT | `gost_4_2_1` |
| остальные (американские надписи без пары) | `gost_2_1` или убрать знак (`Config.Hide` в kavkaz_world) |

3. **Форма.** У американского знака прямоугольная пластина, у нашего — круг/треугольник. Наши PNG с прозрачным фоном:
   - если шейдер знака понимает прозрачность (обычно знаки с «cutout»/alpha) — круг будет круглым, отлично;
   - если нет — по краям будет белый квадрат: тогда эти знаки делаем своими моделями (шаг 3), а американские прячем.

## 3. Свои знаки на столбах там, где их не хватает (новые модели)
Мапперов не берём, модели простые — столб и пластина:
1. Поставить Blender (бесплатный) и аддон **Sollumz** (бесплатный, экспорт в `.ydr/.ytyp` для GTA/FiveM).
2. Скрипт `setup/models/make_signs_blender.py` (запуск `blender -b -P ...`): серый столб Ø 60 мм высотой 2,5 м + пластина нужной
   формы (круг 700 мм, треугольник 900 мм, квадрат 700 мм, ромб, восьмиугольник, табличка населённого пункта) с нашей текстурой,
   простая коллизия столба. Экспорт в ресурс `resources/[kavkaz]/kavkaz_signs/stream/` (`kv_sign_<код>.ydr` + `kavkaz_signs.ytyp`).
3. Расстановка: таблица в `kavkaz_signs/config.lua` `{ model, coords = vec4(...) }`; координаты основатель собирает `/mypos`
   (на въездах в Нагорск, у автовокзала, МРЭО, переходов в центре, на серпантине). Сначала через `CreateObject` по близости,
   если знаков станет больше 200 — собрать `.ymap`.
4. Проверить: знак не висит в воздухе, видно обе стороны (обратная сторона — серая), в машину не врезается «насквозь».
