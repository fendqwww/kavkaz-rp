## Задача 1 (главная): перепаковщик текстур YTD — машины не спавнятся
FiveM пишет «Oversized assets … models not loading»: у `.ytd` машин огромная физическая память
(g63 128 МБ, jesko 110, camry70 92, granta 90, zeekr001 82, vaz2107 79, camry80 70, lc300 70, chiron 68, liaz 66,
gazel / roadster / zeekr001_livery 64). Из-за этого Камри 80 и другие не появляются.

`setup/cars/shrink_ytd.py` уже срезает верхний mip (4K→2K, 2K→1K) и **зануляет** старые данные — файл для скачивания
меньше, но размер графических страниц в заголовке RSC7 прежний, память та же.

Сделай `setup/cars/repack_ytd.py <file.ytd> [--max 1024]`:
1. распаковать RSC7 (заголовок 16 байт: `RSC7`, version, sysFlags, gfxFlags; дальше raw deflate). размер сегмента по флагам —
   функция `page_size()` в `shrink_ytd.py`; виртуальный сегмент идёт первым, графический — после него;
2. разобрать словарь текстур (указатель на список текстур — `0x30` системного сегмента, см. `ytdinfo.py`): у текстуры
   ширина/высота/глубина/шаг строки по `+0x50`, формат `+0x58`, уровни `+0x5D`, указатель данных `+0x70` (`0x6xxxxxxx` — смещение
   в графическом сегменте);
3. срезать уровни больше `--max` (как в `shrink_ytd.py`: у текстур с mip — сдвиг на следующий уровень, без mip — прореживание
   блоков/пикселей);
4. **собрать графический сегмент заново** только из нужных цепочек mip (размер цепочки: по уровням, блочные форматы
   DXT1/ATI1 — 8 байт на блок 4×4, DXT3/DXT5/ATI2/BC7 — 16; несжатые — по шагу строки), выровнять по 16 байт,
   разложить по страницам так, чтобы **блок не пересекал границу страницы** (страницы: base = `0x200 << shift`, размеры
   base×2^k, ограничения количества — см. `page_size()`), записать новые gfxFlags и новые указатели `+0x70`;
5. сжать обратно (raw deflate, level 9), заголовок с новым флагом;
6. проверка: `ytdinfo.py` читает файл, список и размеры текстур совпадают с ожиданием, `page_size(gfx)` = длине данных.

Тестовые файлы: машин в git нет. Возьми любой `.ytd` машины из своих скачанных модов или собери машину
`setup/cars/build.py` (см. `docs/vision/19-car-models-todo.md`). Цель — физическая память ≤ 32 МБ у каждой машины.
Если сделать надёжно не выходит — оставь подробную заметку в `docs/tasks/`, что мешает, и не ломай `shrink_ytd.py`.
