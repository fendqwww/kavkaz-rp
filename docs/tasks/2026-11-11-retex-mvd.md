# Задание для Claude в VS Code: перетекстуровка зданий, начинаем с МВД

Цель: снаружи здания GTA выглядят нашими. Участок Mission Row → **ГУ МВД по Республике Нагорье** («ПОЛИЦИЯ», герб, табличка),
потом ФСБ, военкомат, магазины, кафе. Мапперов не нанимаем, новые здания не строим — меняем вывески на существующих.

Всё нарисовано заранее (33 картинки, `resources/[kavkaz]/kavkaz_world/images/retex/`, превью ниже в таблице).
Нужны только имена текстур GTA и подгонка. В игре подмена идёт через `AddReplaceTexture` (`kavkaz_world/config.lua` → `Config.Textures`).

## Правила
- сначала `git pull`, ветка `claude/serene-franklin-9x1dw5`;
- файлы игры и куски её текстур **в git не кладём**: `.ytd` и выгрузки — в `C:\kavkaz\mods\retex\` (вне репозитория),
  собранные вывески с пикселями игры — в `kavkaz_world/images/local/` (папка в `.gitignore`, на VPS копировать вручную/скриптом);
- чужие перетекстуровки (греческий, датский участок) используем **только чтобы узнать имена текстур**, их картинки не берём;
- стиль — скилл `kavkaz-ui` не нужен (это вывески на зданиях), но правило то же: показать основателю скрин до/после, код — после «да»;
- секреты не выводить, коммиты на русском в повелительном наклонении.

## Шаг 1. Узнать, какие текстуры у участка Mission Row
**Быстрый путь.** Основатель скачивает (кнопка на сайте) один из готовых модов участка:
- https://uk.gta5-mods.com/misc/greek-police-station-re-texture-mission-row
- https://www.gta5-mods.com/ru/misc/fivem-danish-policestation-mission-row (уже под FiveM)

Распаковать в `C:\kavkaz\mods\retex\mission_row_mod\`. Имена `.ytd` в моде = имена словарей текстур GTA, которые меняли.
```
python -I setup\retex\ytd_export.py C:\kavkaz\mods\retex\mission_row_mod C:\kavkaz\mods\retex\out_mod
```
Открыть `out_mod\<ytd>\sheet.html` — видно, какие текстуры с надписями («LSPD», «POLICE», герб).

**Оригиналы GTA** (нужны, если вывеска — часть большой текстуры). Поставить CodeWalker (github.com/dexyfex/CodeWalker, релизы),
RPF Explorer → найти те же `.ytd` по именам из шага выше → «Export» → `C:\kavkaz\mods\retex\orig\`, затем:
```
python -I setup\retex\ytd_export.py C:\kavkaz\mods\retex\orig C:\kavkaz\mods\retex\out_orig
```

## Шаг 2. Подобрать нашу картинку к каждой текстуре
| на здании | наша картинка |
|---|---|
| большая надпись LSPD / POLICE над входом | `facade_police` (синяя) или `facade_police_white` (белая) |
| герб / звезда LSPD | `emb_mvd` |
| табличка у двери | `plate_mvd` |
| вывеска гаража / ДПС | `facade_dps` |

- текстура **целиком** вывеска → строка в `Config.Textures`: `{ txd = '<ytd без .ytd>', txn = '<имя текстуры>', image = 'facade_police' }`;
- вывеска **на части** текстуры → собрать из оригинала:
  ```
  python -I setup\retex\fit.py out_orig\<ytd>\<tex>.png resources\[kavkaz]\kavkaz_world\images\retex\facade_police.png X Y W H resources\[kavkaz]\kavkaz_world\images\local\<ytd>__<tex>.png
  ```
  (X Y W H — прямоугольник, где в оригинале надпись; `--contain` — вписать целиком с полями) и в конфиг `image = 'local/<ytd>__<tex>'`.

## Шаг 3. Проверить
- локальный сервер: `ensure kavkaz_world`, подъехать к участку (навигатор F5 → Госучреждения → ГУ МВД, около 428.9, −984.5);
- проверить днём и ночью, вблизи и издалека. **Издалека может мелькать старая вывеска** — это дальняя модель (LOD) со своей
  текстурой: найти и её (обычно рядом, с `_lod`/`lod` в имени) и добавить в конфиг;
- в консоли не должно быть `[kavkaz_world] нет картинки …`;
- скрин до/после основателю.

## Шаг 4. На VPS
Скопировать `kavkaz_world` целиком (с `images/local`) на VPS 13.141.51.196 и `ensure kavkaz_world`. Если на сервере играют — спросить.
