# Задание для Claude в VS Code: 3D-пульт «Хазард 7007» в салоне

Основатель хочет, чтобы пульт был виден **из салона** (вид от первого лица и через стекло снаружи), детально, как на роликах
«Fort Grozny» / «groznyrb» в TikTok (там пульт сделан моделью: чёрный корпус с «ушами», две ручки, OFF/VOL, HILO/YELP/WAIL/STANDBY,
PA/MAN, RADIO/HORN, две белые кнопки, разъём RJ, табличка PREMIER HAZARD 7007, жёлтая обводка). Образцы: скрины в переписке
11.11.2026, фото пульта `resources/[kavkaz]/kavkaz_sgu/html/unit.png`.

Мапперов и платных моделей не берём — делаем сами, это простая модель (коробка, две ручки, кнопки).

## Шаг 1. Модель
1. Blender (бесплатный) + аддон **Sollumz** (бесплатный, экспорт `.ydr/.ytyp` для FiveM). Ставит Claude, основатель только подтверждает.
2. Скрипт `setup/models/make_hazard_blender.py` (`blender -b -P …`), размеры настоящего блока ≈ 160 × 110 × 45 мм:
   - корпус: скруглённая коробка + боковые «уши» с отверстиями, низ — пластик;
   - лицевая панель: текстура 2048×1408 — **чёткая перерисовка по фото** (не размытое фото): надписи шрифтом, жёлтая обводка,
     табличка PREMIER HAZARD, «7007»; карты normal/specular для рельефа пластика;
   - **две ручки отдельными объектами** (`kv_hazard_knob_vol`, `kv_hazard_knob_sel`) — чтобы крутить их в игре;
   - две кнопки (PA/MAN, HORN) — белые, отдельными объектами (нажатие = сдвиг на 2 мм);
   - светодиоды L1/L2 — отдельные маленькие объекты с эмиссией (горят, когда включена мелодия / стробоскопы).
   Лимит: до 3 000 треугольников, текстуры до 2K — у игроков слабые видеокарты.
3. Экспорт в `resources/[kavkaz]/kavkaz_sgu/stream/` (`kv_hazard7007.ydr`, ручки, кнопки, `kavkaz_sgu.ytyp`, `kv_hazard7007.ytd`)
   и `data_file 'DLC_ITYP_REQUEST' 'stream/kavkaz_sgu.ytyp'` в fxmanifest.

## Шаг 2. Пульт в машине
1. `kavkaz_sgu/config.lua` → `Config.Dash = { [модель] = { bone = 'dashglow' или 'chassis', offset = vec3, rot = vec3 } }`
   — место на торпеде для каждой машины из `kavkaz_cars` (по умолчанию — над центральной консолью справа от руля).
   Подбор места — командой `/sgupos` (двигать стрелками, сохранять в буфер), как `/mypos`.
2. Клиент: когда у машины стоит СГУ (сервер уже знает модель), рядом с игроком (до 30 м) создаётся объект пульта и крепится
   `AttachEntityToEntity` к машине. Объекты не сетевые — каждый игрок создаёт у себя. Убирать, когда машина далеко или СГУ сняли.
3. Ручка выбора поворачивается на текущую мелодию (углы — как `POS` в `html/index.html`), VOL — по громкости,
   L1 горит при включённой мелодии, L2 — при стробоскопах; MAN/HORN «нажимаются» при кряке и ручном тоне.
4. Экранный пульт (NUI) оставить, но **по умолчанию скрыть в виде от первого лица** — там виден 3D; в виде от третьего лица — показывать.

## Шаг 3. Проверка
- днём и ночью, от первого и третьего лица, на Приоре, Камри, Крузаке, УАЗе;
- пульт не проходит сквозь торпеду, не мешает обзору, не дрожит на ходу;
- FPS не падает (пульт — один объект + 4 мелких);
- скрины основателю, код — после «да».
