# Задание для Claude в VS Code: собрать лаунчер 0.3 и выложить

Что изменилось (ветка `claude/serene-franklin-9x1dw5`):
- новый дизайн (скилл kavkaz-ui, обновление 13.11): Onest, оранжевый акцент, новый логотип `ui/img/logo.svg`, без машин и Хазарда;
- **интерфейс теперь подтягивается сам**: `ui/index.html` — загрузчик, при старте берёт свежий `ui/app.html` из репозитория
  (команда `get_remote_ui` в `src-tauri/src/main.rs`), картинки и шрифты — оттуда же по `<base>`. Нет сети — вшитая копия `ui/app.html`.
  После установки 0.3 любые правки `launcher/ui/app.html` в ветке видны игрокам при следующем запуске, без переустановки.
- версия 0.3.0 (`tauri.conf.json`, `Cargo.toml`).
- после «Играть» лаунчер сворачивается и 3 минуты сворачивает окна Rockstar / Social Club / Epic / Steam / заставки FiveM (модуль `quiet`, windows-sys 0.52; окно игры …GTAProcess не трогает). проверить на ПК: окна уходят в панель задач, вход в аккаунт Rockstar можно развернуть.

Сделать:
1. `git pull`, собрать: `cd launcher\src-tauri && cargo tauri build` (в Linux-контейнере не собирается — нет GTK).
2. Проверить: запуск с интернетом (интерфейс из репозитория) и без (вшитый).
3. Выложить установщик в релиз `launcher-latest` (как 0.2), старый файл заменить.
4. Старые 0.2 сами не обновятся: им показывается новость «Новый лаунчер 0.3» из `launcher/config.json` — после выхода релиза её оставить.

Потом (по желанию): `tauri-plugin-updater`, чтобы и сам exe обновлялся без ручной установки (нужен ключ подписи, хранить вне git).
