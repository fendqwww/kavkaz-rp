# Задание для Claude в VS Code: русские знаки и щиты на карте

Ресурс `resources/[kavkaz]/kavkaz_world` уже умеет подменять текстуры GTA нашими картинками (`images/*.png`) прямо в игре.
Не хватает одного: **имён текстур GTA**, которые надо заменить. Их можно узнать только из файлов игры (у тебя GTA на ПК).

1. Найди в файлах GTA (CodeWalker → RPF Explorer, поиск; или `setup/cars/rpf.py` + `setup/cars/ytdinfo.py`) словари текстур:
   - дорожные указатели и знаки у трасс (ищи `sign`, `freeway`, `road_sign`, `hw_sign`);
   - рекламные щиты (ищи `billboard`, `bboard`, `ad_`);
   - таблички въезда в города, если есть.
2. Для каждой подходящей текстуры запиши строку в `Config.Textures` (`kavkaz_world/config.lua`):
   `{ txd = 'имя словаря', txn = 'имя текстуры', image = 'наша картинка' }`. картинки: `city_*`, `dir_*`, `ad_*`.
   соотношение сторон: знаки 2:1, щиты 2:1. если у текстуры GTA другое — поправь размеры в `setup/signs/make_signs.py` и перерисуй.
3. Начни с 3–5 самых заметных (щиты в центре, указатели на въезде), проверь в игре, сделай скрин до/после.
4. Американские надписи на зданиях и магазинах не трогай пока — только знаки и щиты.
5. Секреты не выводить, файлы игры в git не класть (только имена текстур в config.lua). Коммит на русском, пуш в ветку.
