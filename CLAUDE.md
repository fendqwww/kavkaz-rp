# KAVKAZ RP — правила проекта

RP-сервер для FiveM на фреймворке **Qbox** (qbx_core + ox_lib / oxmysql / ox_inventory / ox_target), база **MariaDB**, управление через **txAdmin**.

## Общение
- отвечать на русском, с маленькой буквы.
- игровые тексты (уведомления, меню, локали) — на русском; код, имена переменных и ресурсов — на английском.

## Где что лежит (Windows)
| путь | что |
|---|---|
| `C:\kavkaz\server` | артефакты FXServer (recommended-билд) |
| `C:\kavkaz\txData` | данные txAdmin и задеплоенный сервер Qbox (`resources`, `server.cfg`) |
| `C:\kavkaz\secrets.cfg` | пароли БД, строка подключения, ключ Cfx.re — **только локально** |
| `C:\kavkaz\kavkaz-repo` | этот репозиторий |
| ярлыки на рабочем столе | «Запустить сервер» / «Остановить сервер» |

Установка с нуля: `setup/install.ps1` (идемпотентный, можно перезапускать).

## Секреты — железное правило
- пароли, `sv_licenseKey`, `mysql_connection_string`, steam/discord-токены **никогда** не попадают в git, в чат, в логи и в issues.
- в `server.cfg` секреты подключаются только через `exec C:/kavkaz/secrets.cfg`.
- перед каждым коммитом проверять `git diff --cached` на пароли и ключи (`cfxk_`, `mysql://`, `password`).

## Ресурсы
- свои ресурсы — префикс `kavkaz_` (например `kavkaz_jobs`), папка `resources/[kavkaz]`.
- чужие ресурсы не правим напрямую: переопределяем через конфиги/экспорты; если без правки никак — правка помечается комментарием `-- KAVKAZ:` и описывается в коммите.
- используем API Qbox/ox (`exports.qbx_core`, `lib.callback`, `MySQL.query.await`), а не устаревший `QBCore.Functions`, если есть аналог.
- в `fxmanifest.lua`: `fx_version 'cerulean'`, `game 'gta5'`, `lua54 'yes'`, зависимости через `dependencies`.
- вся логика с деньгами, предметами и правами — **на сервере**; клиенту не доверяем, серверные события проверяют `source`, дистанцию и права.
- SQL только параметризованный (`?`), никакой склейки строк.
- изменения схемы БД — отдельным `.sql` файлом в `sql/` с датой в имени.

## Git
- ветки: `main` — рабочая; фичи — `feature/<коротко>`; коммиты на русском, в повелительном наклонении («добавь…», «исправь…»).
- в репозиторий не коммитим артефакты сервера, `txData`, кэш, логи, архивы (см. `.gitignore`).

## Проверка изменений
- перезапуск ресурса из консоли txAdmin: `ensure <ресурс>`; смотреть ошибки в консоли сервера и F8 клиента.
- вход на локальный сервер: FiveM → F8 → `connect 127.0.0.1`.
